# Initial public preview

ZT Control Plane `v0.1.0` is the first versioned public release. It provides one
private management workspace for self-hosted ZeroTier One Network Controllers,
MikroTik RouterOS, New Central, Legacy Central, and supported managed nodes.

## Install the standard image

The published image contains only the unprivileged open-source control-plane
runtime:

```sh
docker pull ghcr.io/dobria/zt-control-plane:0.1.0
```

For Docker Compose, download `compose.release.yaml` from the `v0.1.0` source or
clone the repository at that tag, copy `.env.example` to `.env`, and run:

```sh
docker compose -f compose.release.yaml up -d
```

Open <http://localhost:3100/setup> and follow the one-time administrator setup.
Read the deployment and security documentation before exposing the interface
outside a trusted network.

## Highlights

- Manage multiple controller providers without hiding object ownership.
- Search networks and node memberships across registered controllers.
- Manage supported network, member, route, DNS, address-pool, and Flow Rule
  operations.
- Inspect and configure remote ZeroTier One and RouterOS client runtimes.
- Work with multiple ZeroTier instances and hosted controllers on one RouterOS
  device.
- Use roles, TOTP 2FA, IP access rules, audit history, diagnostics, and encrypted
  provider credentials.
- Keep healthy providers responsive when another endpoint is unavailable.

## Compatibility and boundaries

- Published image: `linux/amd64`.
- Persistent state: one SQLite-backed application replica with `/data` stored
  on a durable volume.
- Upgrade safety: create and verify a full `/data` backup before replacing the
  image.
- Provider behavior: consult the capability matrix because equivalent-looking
  APIs do not always expose equivalent operations.
- Embedded controller: not published in GHCR; build it separately only after
  reviewing the upstream ZeroTier licensing and host privilege requirements.
