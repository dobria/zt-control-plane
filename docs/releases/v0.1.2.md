# RouterOS Joined network reliability

ZT Control Plane `v0.1.2` improves client-interface management for MikroTik
RouterOS ZeroTier instances.

## What changed

- New RouterOS Joined networks are created with the smallest compatible REST
  payload and leave unchanged defaults to RouterOS.
- Existing Joined networks receive only the settings that the operator changed.
- RouterOS validation and provider errors remain visible inside the edit dialog.
- Regression coverage verifies that unchanged interface fields do not trigger
  a RouterOS write.

The change was validated against a real RouterOS deployment for both creating
and editing Joined networks. It does not require a database migration.

## Upgrade

Back up the persistent `/data` volume, then pull the immutable release image:

```sh
docker pull ghcr.io/dobria/zt-control-plane:0.1.2
```

The same build is also published to Docker Hub:

```sh
docker pull dobria/zt-control-plane:0.1.2
```

Recreate the application container using the new image. Existing SQLite state,
controller registrations, encrypted credentials, and user settings remain in
the persistent `/data` volume.
