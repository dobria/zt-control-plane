# HTTP client security and frontend maintenance

ZT Control Plane `v0.1.4` updates its direct HTTP client dependency with
upstream security fixes and refreshes the frontend runtime as a coordinated
maintenance release.

## What changed

- Undici is updated to 8.10.2. The upstream release addresses issues involving
  cache isolation and unsafe method caching, shared `Set-Cookie` responses,
  decompression limits, resumed-response framing, TLS option preservation, and
  WebSocket failure handling.
- React and React DOM are updated together to 19.3.0, with matching TypeScript
  definitions.
- Lucide React is updated to 1.44.0.
- The complete application test suite, production build, container build, and
  CodeQL analyses pass for the combined dependency update.

This release does not require a database migration.

## Upgrade

Back up the persistent `/data` volume, then pull the versioned standard image:

```sh
docker pull ghcr.io/dobria/zt-control-plane:0.1.4
```

The same build is also published to Docker Hub:

```sh
docker pull dobria/zt-control-plane:0.1.4
```

Update the image reference in your deployment and recreate the application
container with the existing `/data` volume. Verify `/api/health`, sign-in,
controller reads, and representative network operations. SQLite state,
registered controllers, encrypted credentials, and user settings remain in
the persistent volume.

Published images support `linux/amd64`. The optional embedded-controller image
is built locally and remains subject to the separate upstream licensing terms.
